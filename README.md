# 维家智能空间交互 Demo

基于维家一期 PRD 第六章及 P0 场景的手机端前端演示。保留“示例问题引导 + 对话中逐步插入卡片”的交互方式，首页视觉结合智能空间与 AI 健康参考图重新设计。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址。桌面浏览器显示手机预览框；手机浏览器显示全屏界面。

## 演示内容

- 默认进入聊天页，顶部用「对话 / 我的」文字导航切换：首页有带淡化 W 标识的光球、固定两列的快捷指令、空间速览卡和推荐场景；发送问题后，对话会接在首页内容下方，可向上滚动回看。
- 底部是完整的圆角输入栏：左侧语音说明、中央文字输入、右侧紧凑的更多功能按钮；输入文字后右侧按钮变为发送。
- 「我的」页提供家庭资料、设置及空间、消息入口。本次浏览器会话中的对话与任务会保存在 sessionStorage，刷新后可以继续演示。
- 「我的」页家庭卡片下方可切换标准、静音和隐私模式；「隐私与数据授权」也可进入。静音保留文字输入，隐私模式暂停对话并在首页显示状态；切换前说明影响、安全例外、持续时间和恢复方式。模式状态与最近三次切换只保存在本次浏览器会话中。
- 页头“返回”回到上一级页面或欢迎页，“关闭”重置本次演示会话。浏览器 H5 无法直接关闭微信小程序。
- “客厅有点热”：状态依据、方案确认、执行中和设备回读结果。
- “打开客厅灯”：低风险控制和设备回读；未指定房间时追问。
- “离家模式”：影响范围、二次确认和分项部分失败。
- 个性化家庭问答：组合设备状态与房屋档案，并标明来源。
- 文字输入不限于示例问题：可用不同说法询问空间温度、设备状态、家庭概况、任务、资料等；缺失信息会明确说明，设备控制继续遵守确认流程。
- 模拟燃气传感器事件：高优先级事件卡、处置指引、通知确认和事件详情。
- 空间、消息、我的、任务详情、设备详情、房屋资料详情等基础页面。
- 右上角“···”可切换演示场景、模拟设备离线或重置数据。
- 演示菜单中的「首访绑定」「恢复历史任务」「异常状态原型」进入状态库，可在顶部下拉切换首访、空间、消息、任务、事件、设备、资料和权限等原型。也可直接打开 `?prototype=first-visit`、`?prototype=history`、`?prototype=offline` 等深链。首访绑定有两步确认；历史任务可恢复到对话中的待确认卡片。状态库使用本地示例数据，供评审状态和文案，不代表接口已接通。

所有家庭、设备、资料和事件均为**本地模拟数据**；没有调用 AI、公司接口或真实硬件。模式切换也只改变 Demo 的入口状态，不会控制真实麦克风、面板或传感器。燃气事件只能通过演示面板模拟传感器触发，输入文字不会触发真实安全动作。控制任务的“回读”也仅是模拟交互状态。

PRD 6.9 将完整卡片体系列为 V2；本 Demo 用于验证完整卡片交互，不代表一期 V1 已承诺交付全部卡片能力。

## 构建与部署

```bash
npm run build
```

构建产物在 `dist/`，可作为静态文件放到公司服务器的站点目录。项目使用相对资源路径，不依赖本机开发服务，也无需后端。上线前需要由研发接入真实身份、家庭权限、设备状态、任务和事件接口，并把模拟数据与模拟回读替换掉。

## 后续调整 UI

页面和交互逻辑在 `src/App.tsx`。基础组件样式在 `src/styles.css`；首页视觉集中在 `src/visual-refresh.css`。维家 Logo 使用用户提供的 `public/brand-logo.png`。后续调整颜色、字号、间距和卡片，优先修改视觉方案文件，再逐个场景检查正常、离线、失败和告警状态。
